Liens du cours Scratch Junior

Les liens partagés par toutes les classes du cours : généraux, ou propres à une séance (1 à 14). Les professeurs du cours les adaptent pour tous.

Ces liens sont visibles par toutes les classes de ce cours (Scratch Junior — mercredi 14h–17h, Scratch Junior — samedi 9h–12h) et par les élèves via le code de partage. Chaque modification est enregistrée à votre nom et peut être annulée pendant 6 mois.
🔒

Vous n’enseignez pas ce cours

Seuls les professeurs ayant une classe active de Scratch Junior, la direction et l’administration peuvent modifier ses liens. Vous pouvez consulter les liens : demandez à la direction de vous assigner à une classe pour les adapter.
