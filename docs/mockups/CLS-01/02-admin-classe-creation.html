Nouvelle classe

Un seul formulaire : le cours, le créneau, la première date et les professeurs. Les 14 sessions sont générées à la validation.

Chargement du formulaire…
La classe n’a pas pu être créée. Aucune session n’a été générée (l’opération a été annulée en entier). Corrigez la date de première session puis réessayez.
Le calendrier scolaire 2026-2027 est vide. Sans lui, les sessions ne pourront pas sauter les vacances ni les jours fériés. Importez d’abord le calendrier FWB.
