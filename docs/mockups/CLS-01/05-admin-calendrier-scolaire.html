Impact avant enregistrement
  • 1 session existante tombe sur cette date : React mercredi, séance 9 (16/12/2026).
  • Elle ne sera pas déplacée automatiquement : une alerte s’affichera sur la classe pour que vous la déplaciez, l’annuliez ou la mainteniez.
