Une classe = une ligne, quel que soit le nombre de périodes. Le nom affiché est « Cours P1 → Cours P2 » (ou le cours unique si les deux sont identiques ou si P2 est absente). Une classe sans P2 affiche « P2 à planifier » (alerte quand la P1 est à moins de 4 semaines de sa fin) ; une classe qui démarre en P2 affiche « P1 à ajouter ». « Hors période » signale des séances au-delà de la fin de leur période (non bloquant).
