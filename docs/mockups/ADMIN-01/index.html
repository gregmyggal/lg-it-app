ADMIN-01 — Gestion des comptes admin et directeur

Maquettes statiques à valider (aucun développement avant validation). Voir WORKFLOW_UX.md.

  • 01-liste-staff-filtre.html — Liste des admins et directeurs avec filtres rôle/statut (états : chargement, vide, erreur, succès)
  • 02-creation-modale.html — Création d'un admin/directeur, mot de passe généré affiché une fois, erreur email pris
  • 03-fiche-detail-compte.html — Fiche détail : bloc Compte de connexion (réinitialiser, désactiver/réactiver, changer email)
  • 04-confirmation-desactivation.html — Modale d'impact et confirmation de désactivation (classes assignées, sessions à venir, auto-désactivation impossible)

Notes de conception

  • Isolement strict : seul l'admin peut gérer les admins/directeurs ; directeur n'a pas accès à ce menu.
  • Mot de passe généré : serveur génère 12 caractères, affiché une seule fois, changement forcé à la connexion.
  • Désactivation = action dédiée : modale d'impact, pas de suppression dure (historique conservé).
  • Statut backend : vérification côté login + middleware, jamais seulement côté UI.
  • Audit trail : chaque action loggée (qui, quand, rôle, ancien/nouveau statut).
